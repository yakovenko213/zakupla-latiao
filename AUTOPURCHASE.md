# Автозакупка — розгортання

1. Створіть секрет шифрування: `firebase functions:secrets:set AUTOPURCHASE_ENCRYPTION_KEY` (довге випадкове значення).
2. Виконайте `npm install` у каталозі `functions/`.
3. Виконайте `firebase deploy`.

Таблицю слід завантажити з Google Sheets у форматі Microsoft Excel (`.xlsx`), а потім вибрати у формі «Джерела». Сервер читає всі несистемні вкладки й зберігає нормалізовані рядки частинами у колекції Firestore `autopurchaseSources`; OpenAI файл не отримує.

OpenAI-ключ шифрується AES-256-GCM у Firestore, ніколи не повертається клієнту й не пишеться в логи. Без ключа розрахунок, оптимізація, читання й запис таблиць працюють без ШІ.
