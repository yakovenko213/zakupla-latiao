Додати у фін облік?

Вартість за шт = Сума закупки ÷ К-сть
Планова доставка = Загальна вага рядка × Ставка (у ₴)
Планова собівартість = Вартість за шт + Планова доставка ÷ К-сть
Фактична собівартість = Вартість за шт + Фактична доставка ÷ К-сть
Маржа = (Роздріб − Собівартість) ÷ Роздріб. Береться фактична собівартість, а якщо її немає, планова.
Фактична доставка та планова доставка вказуються у гривнях (₴). Вага вводиться загалом за всю кількість товару в рядку.
Обʼєднані клітинки: сума закупки, планова та фактична доставка діляться між рядками групи (доставка за вагою × к-сть), решта значень діють для всіх рядків групи.

🔥 База даних Firebase

Підключіть Firebase Firestore для синхронізації та збереження всіх закупок, товарів каталогу та фінансових записів у реальному часі.

Перевірка...
📖 Як створити базу Firebase за 2 хвилини?
  1. Відкрийте Firebase Console та створіть новий проект (або відкрийте існуючий).
  2. У лівому меню виберіть Build → Firestore Database і натисніть Create database.
  3. У вкладці Rules (Правила) дозвольте доступ на читання й запис: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  4. Відкрийте Project Settings (шестерня) → General, у розділі Your apps натисніть </> (Web).
  5. Скопіюйте обʼєкт firebaseConfig і вставте у поле вище.
